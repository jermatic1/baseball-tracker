Each row is a track the detector linked. a = accept as ball, r = reject, A = accept every moving track in the clip. j / k = next / previous track, n / p = next / previous clip. The next clip opens when every track here is reviewed. t = per-frame view at this track.

Click the ball. A gap of up to 12 frames is filled in a straight line. n = no ball. u = undo this frame. e = no ball anywhere in this clip, then the next clip; e again on a marked clip unmarks it. t = back to tracks.
